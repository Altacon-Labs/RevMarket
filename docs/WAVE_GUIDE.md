# Wave participation guide

Documentation checked on 28 October 2026. Program settings can change; the live Drips app determines approval, cycle dates, enrollment, budgets and assignments.

## Maintainers

Follow [onboarding](https://docs.drips.network/wave/maintainers/participating-in-a-wave/): connect GitHub, install the Wave app for the repository's organization, sync a public repository, and apply to the relevant program. Enrollment requires organizer approval. Verify personal-account repository support if applicable. Do not present this local package as already approved.

## Points and rewards

Maintainers propose issue complexity: Trivial 100, Medium 150, High 200 points. These are not fixed dollar rewards. The standard pool allocation is proportional to points, subject to organizer adjustments and program-specific rules. Adding an issue via the GitHub program label defaults to Trivial; update harder issues in the dashboard. See [points](https://docs.drips.network/wave/points-and-rewards/) and [maintainer FAQ](https://docs.drips.network/wave/maintainers/faq/).

The [points budgets](https://docs.drips.network/wave/maintainers/points-budgets/) may cap both repo and org totals. Check available budget before enrolling issues; unresolved work can carry budget usage forward. The first-Wave set proposes 500 points, not a confirmed allowance or reward commitment.

## Contributors

For funded Wave work, complete Drips identity verification, apply in Drips, and wait for official assignment. Use a PR closing reference only for complete work. Points depend on the assigned issue being resolved/closed as completed in the active cycle; a merge alone is insufficient. Read [contributor workflow](https://docs.drips.network/wave/contributors/solving-issues-and-earning-rewards/) and [contributor FAQ](https://docs.drips.network/wave/contributors/faq/). Do not send identity documents to this project.

## Standards

Submit work you understand and can verify; clearly identify assisted work, fixture evidence and limitations. Ordinary contributions outside Wave have no implied payment. Follow [Drips terms](https://docs.drips.network/wave/terms-and-rules/) and the repository's conduct and security policies. No issue draft establishes funding, eligibility, enrollment or assignment.
