# Community conduct

Treat contributors respectfully. Discuss the code and evidence, give clear and actionable feedback, and welcome different experience levels. Ask for clarification before assuming intent. Respect people's time, attribution, identity and privacy.

Harassment, threats, discrimination, doxxing, spam, impersonation and deliberately misleading reward or assignment claims are unacceptable. Do not request private keys, wallet recovery phrases or identity documents from another contributor. Drips identity verification belongs in its own official flow.

The repository owner and appointed maintainers moderate issues and pull requests. They may edit or remove abusive content, warn a participant, or restrict participation proportionately. For a private report, use GitHub private vulnerability reporting when enabled or an existing private contact published on the repository owner's GitHub profile. Do not publish sensitive evidence in an issue. If no private route is available, request a private contact without describing sensitive details publicly. Wave participation disputes may also be raised through Drips support.
